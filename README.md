# AI Resume Builder

An AI-powered resume builder developed during our IBM Internship, applying the concepts and technologies we learned throughout the internship program.

## About

AI Resume Builder helps users create professional resumes with the help of AI-powered content suggestions and customizable resume templates.

The project was developed as part of our IBM Internship project.

## Tech Stack

* **Frontend:** React, TypeScript, Vite
* **Backend:** Node.js
* **Database:** MongoDB
* **AI:** AI-powered resume content generation

## Features

* AI-generated resume content suggestions
* Professional resume templates
* Resume content management
* Fast and user-friendly interface
* Easy resume creation and editing

## How to Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/Rounakk09/Ai_Resume-Builder.git
cd Ai_Resume-Builder
```

### 2. Install Dependencies

```bash
bun install
```

### 3. Configure Environment Variables

Create a `.env` file using `.env.example` as a reference and add your required API keys and configuration values.

### 4. Start the Development Server

```bash
bun run dev
```

The application should now be available on the local development server.
